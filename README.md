# ⚡ Salesforce Developer Handbook

An interactive, developer-focused knowledge hub for exploring Salesforce architecture, platform development, automation, integrations, and engineering best practices.

Built as a personal learning and reference resource, this project brings core Salesforce concepts together in a structured, easy-to-navigate experience inspired by guided technical learning platforms.

🔗 **Live Demo:** [Explore the Salesforce Developer Handbook](https://rushikesh-kale-ip.github.io/salesforce-rushikesh-handbook-react/#/learningroute/lwc/1)

## 🚀 Overview

The Salesforce Developer Handbook is designed to make complex platform concepts easier to revisit, understand, and apply. It combines structured learning paths, technical explanations, and practical examples in an interactive React-based interface.

The project reflects my interest in building useful developer tools, organizing technical knowledge, and creating engaging learning experiences while continuously strengthening my Salesforce engineering skills.

## 🧩 Key Technical Areas

The handbook covers a broad range of Salesforce development concepts, including:

- **Salesforce Platform Architecture:** Platform fundamentals, execution context, multitenancy, and application architecture.
- **Data Modeling:** Standard and custom objects, relationships, schema design, and data management.
- **Apex Development:** Object-oriented programming, classes, collections, exception handling, and asynchronous Apex.
- **SOQL & SOSL:** Data retrieval, query optimization fundamentals, filtering, relationship queries, and search.
- **Triggers & Automation:** Trigger execution, bulkification, trigger frameworks, order of execution, and automation design.
- **Lightning Web Components (LWC):** Component architecture, JavaScript, data binding, events, lifecycle hooks, and component communication.
- **Salesforce Flow:** Screen Flows, record-triggered automation, reusable logic, and Flow Orchestration concepts.
- **Security & Access Control:** Profiles, permission sets, sharing, object permissions, field-level security, and secure development practices.
- **Integrations:** REST APIs, Platform Events, integration patterns, and communication between Salesforce and external systems.
- **Deployment & DevOps:** Salesforce CLI, source control, Git workflows, CI/CD concepts, and release management.
- **Interview Preparation:** Scenario-based questions, implementation considerations, and practical problem-solving topics.

## 💻 Run Locally

To run the project on your local machine:

```bash
# Clone the repository
git clone https://github.com/rushikesh-kale-ip/salesforce-rushikesh-handbook-react.git

# Navigate to the project
cd salesforce-rushikesh-handbook-react

# Install dependencies
npm install

# Start the development server
npm run dev
npm run build
npm run deploy
```

Open the local URL displayed in your terminal, typically `http://localhost:5173/`.
